# Web Agencia de Viajes ✈️

## 📋 Descripción

Este proyecto consiste en el desarrollo de una página web para una agencia de viajes.

El objetivo es presentar información sobre viajes y destinos mediante una web sencilla y organizada.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño y estilos visuales.

## 📁 Estructura del proyecto

- Archivos HTML: contienen las distintas páginas de la web.
- Archivo CSS: define los estilos y la presentación.
- Carpeta `img/`: contiene las imágenes utilizadas en el proyecto.
